# Product Roadmap

## MVP
- Public careers website: home, about, jobs list/search, job detail, apply form, news list, news detail.
- CMS/admin: dashboard, jobs management, news management, applications management, settings.
- Supabase-backed database for jobs, applications, news, settings, and admin profiles.
- Supabase auth and protected admin routes.
- Deployment-ready Next.js application with environment documentation.
- Design reuse from `.design` HTML exports and screenshots.

## Post-launch
None yet. Focus on shipping the full MVP first.

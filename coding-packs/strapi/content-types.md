# Strapi CMS Content Types

This document defines the schema for the Strapi content types used by the Corporate Website.

## 1. Job (`job`)
- `title` (text, required)
- `slug` (uid, required)
- `locale` (text, required, default `vi`)
- `category` (text)
- `location` (text)
- `employmentType` (text)
- `salaryRange` (text)
- `skills` (json/list)
- `description` (richtext)
- `requirements` (richtext)
- `benefits` (richtext)
- `status` (enumeration: `draft`, `review`, `published`, `closed`, `archived`)
- `publishedAt` (datetime)
- `expiresAt` (datetime)

## 2. Article/News (`article`)
- `title` (text, required)
- `slug` (uid, required)
- `locale` (text, required)
- `excerpt` (text)
- `body` (richtext)
- `coverImage` (media)
- `category` (text)
- `tags` (json/list)
- `author` (text)
- `status` (enumeration)
- `publishedAt` (datetime)

## 3. Application (`application`)
- `candidateName` (text)
- `candidateEmail` (text)
- `candidatePhone` (text)
- `job` (relation to `job`)
- `cvFile` (media)
- `message` (text)
- `status` (enumeration: `pending`, `reviewed`, `accepted`, `rejected`)

## 4. Site Setting (`site-setting`)
- `locale` (text)
- `siteTitle` (text)
- `contactEmail` (text)
- `socialLinks` (json)
- `footerContent` (richtext)

## 5. About Page (`about-page`)
- `locale` (text)
- `title` (text)
- `intro` (text)
- `stats` (json)
- `activity` (richtext)

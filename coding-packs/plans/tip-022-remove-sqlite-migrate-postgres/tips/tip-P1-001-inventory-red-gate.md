# tip-P1-001 — Inventory + Red Gate

## Goal

Build exact SQLite migration inventory and create failing Red Gate tests before implementation.

## Instructions

1. Search active runtime code for SQLite dependencies and syntax.
2. Update `POSTGRES-MIGRATION-INVENTORY.md` with files and planned actions.
3. Create tests/specs mapped to `specs/*.md`.
4. Run targeted tests and capture expected failures in `.zflow/red-gate.md`.

## Acceptance

- Inventory covers all active SQLite runtime surfaces.
- Red Gate tests compile and fail for current implementation.
- No runtime implementation files are migrated in this tip.
